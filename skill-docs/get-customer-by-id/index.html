Get Customer by ID

Overview

The Get Customer by ID skill is a working example of a skill that uses a query parameter to pass values. The skill will prompt the user to input an ID (any integer in 11-16), and passes that ID as a query parameter when calling an API using the HTTP GET method. The API returns the corresponding customer name. The skill user prompt and response can be seen below. In this example, I provide "11" as the customer ID:


Here you can see an example response where I chose a different customer ID (e.g. 12):

Learning Objective

The main purpose of the Get Customer by ID skill is to demonstrate how skills work with query parameters. This skill prompts the user and passes the input via the HTTP query parameter.

API Details

Here you can review the Get Customer by ID query parameter and response object look when using Postman to query the API.

Skill Input Specification

Below you can see in the skill specification section related to the query parameter. Note that this skill does not have a request body (it is a HTTP GET call, therefore not required) but it does contains a parameters section, where the query parameter "customer_id" is specified. 

            "get": {
                "summary": "Get Customer by ID (demo)",
                "description": "Get Customer by ID (11 - 15)",
                "parameters": [
                    {
                        "name": "customer_id",
                        "in": "query",
                        "description": "enter customer ID between 11 - 16",
                        "schema": {
                            "type": "string"
                        }
                    }
                ],
