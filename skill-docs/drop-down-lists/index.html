Drop Down lists

Overview

The Drop Down lists skill presents the user with three drop down lists (an item, a name and color) and passes those selections in the body when calling an API using the HTTP POST method. The API returns a simple message informing the user of the selections. The skill initial user prompt with each drop down list, and skill response can be seen below.

This skill specification contains three skills. Drop Down lists, List first names and List Colors and ids. When you are installing this skill, be sure to select all three, and proceed to enanance each one. Here is a screenshot of each skill being added to my catalog.

Learning Objective

The main purpose of the Drop Down lists skill is to introduce three types of drop down lists. As you may recall, in the Select Name skill, we introduced drop down lists that were hard coded as ENUMs. In addition to an ENUM based drop down list, this skill also includes two other drop down lists, where the content were dynamically populated in the drop down list. Intrigued at the possibility? read on.

Static ENUM drop down list Specification

Below you can see in the skill specification for the first drop down list. The items in the list are hard coded in the skill spec. You can see the three items in the list, in the ENUM array below. The selection, along with the other two lists, will be included in the request body inside the string "hard_coded_enums".

    "hard_coded_enums": {
    "type": "string",
    "x-ibm-show": "true",
    "description": "this is a hard coded list of items",
    "enum": [
        "First Item",
        "Second Item",
        "Third Item"
    ],
    "x-ibm-list": "dropdown",
    "default": "Second Item"
    },

Dynamic drop down list of first names

Below you can see in the skill specification section for the second drop down list (names). The list items that are presented to the user, are feteched from another skill, the List First names skill. In the specification below, you can see the use of "x-ibm-extension", which contains an "action" that calls the remote skill. The selected name is passed along with the previous selection (hard_coded_enums) and the next selection (colors), and will be included in the request body when calling the API.

    "name": {
    "type": "string",
    "description": "this is a dynamic list sourced from ListNames skill",
    "x-ibm-ui-extension": {
        "component": "dropdown",
        "actions": [
        {
            "skill_id": "demo_skills__0.1__list_first_names.demo.get",
            "type": "data",
            "params": {}
        }
        ]
    }
    },

Here is the output of the List First names skill. As the name implies, the output is a simple array of single items (names).

    [
        "James",
        "Julie",
        "Jasper",
        "Jane",
        "Jeff",
        "Jezebel"
    ]

Dynamic drop down list of colors and ids

Below you can see in the skill specification section for the third drop down list (colors). The list items that are presented to the user, are feteched from another skill, the List Colors and ids skill. In the specification below, you can see the use of "x-ibm-extension", which contains an "action" that calls the remote skill. This use of "x-ibm-extension", uses "mappings" feature to identify which items from the output of List Colors and ids will be displayed (e.g. Label) and which items will be passed as the value.

The selected color is passed along with the previous two selections hard_coded_enums and colors, and will be included in the request body when calling the API.

    "colors": {
    "type": "string",
    "x-ibm-ui-extension": {
        "component": "dropdown",
        "description": "This list is dynamically sourced from List Colors skill",
        "actions": [
        {
            "skill_id": "demo_skills__0.1__list_colors.demo.get",
            "type": "data",
            "mappings": {
            "labels": "arrayOfColors.items.properties.label",
            "values": "arrayOfColors.items.properties.value"
            },
            "params": {}
        }
        ]
    }
    }

Here is the output of the List of Colors and ids skill. The output is an array "arrayOfColors" containing object items, where the "label" is the name of the colro and the "value" is the id of the color. 

{
    "arrayOfColors": [
        {
            "label": "Red",
            "value": "#FF0000"
        },
        {
            "label": "Blue",
            "value": "#0000FF"
        },
        {
            "label": "Green",
            "value": "#008000"
        },
        {
            "label": "Yellow",
            "value": "#FFFF00"
        }
    ]
}
