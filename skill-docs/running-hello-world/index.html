Using Natural Language

Alternately, if you prefer typing natural language, try to type in the phrase "Hello World" in the dialogue box. You will see that Watsonx Orchestrate prompts you to clarify which skill. If you recall from the Enhance skill page where we configured some phrases, the skill name was used to train Watsonx Orchestrate. The skill name is *Hello World (demo). Becuase you did not train Watsonx Orchestrate with this exact phrase, it is asking you a clarifying question to make sure it understands you intent. This is a feature we call 'disambiguation'.
