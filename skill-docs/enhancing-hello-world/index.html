Enhancing Skills

This section covers a few of the enhancements features that are available when publishing a skill to the catalog. Note that the Hello World skill specification does not require any specific enhancements, I thought it would be useful to document the options so you are familiar with them

Name

In this page, you can modify the skill name and description. You can also add a category incase you want to group the skills.

Input

Here you can modify the skill inputs. Since the Hello World skill has no input, there is nothing you can do on this screen.

Here is a screenshot of the Skill input details. You can access these details by clicking on the skill, from whithin the skill catalog.

Output

Here you can modify what gets displayed after the skill runs, the skill output. The Hello World skill will output a response from the API. As you can see the label is Response and it is configured to display the message that is returned via the API.

Here you can see the actual response from the Hello World API call

Here is a screenshot of the Skill output details. You can access these details by clicking on the skill, from whithin the skill catalog. Again, since Hello World does not take any input, this screen is blank.

Security

Here you can see the skills security related information such as the authentication method and server URL. In a future release we will provide options to edit these settings.

Phrases

In this page, you can train Watsonx Orchestrate with specific phrases that Cassie can use for initiating the Hello World skill. As you can see, some phrases are already set by default. Note that you can also set these phrases in the *Hello World skill spec file.

Next Best Skill

In this page, you can configure Watsonx Orchestrate to reccomend additional skills to Cassie after running the Hello World skill. Note that you can also set these phrases in the *Hello World skill spec file. We will demonstrate this feature in a more advanced section of the documentation.
