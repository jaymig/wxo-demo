Hello Name

Overview

The Supported Data types skill prompts the user to input each of the supported data types and returns the entries back to the user. This skill uses an HTTP POST method. The skill user prompt and response can be seen here:

Learning Objective

The main purpose of the Supported Data Types skill is to demonstrate each of the supported data types. The secondary purpose is to demonstrate the 'Richly formatted skill description' feature.

API Details

Here you can review the Supported Data Types raw API request body and response object.

Skill Input and Description Specification

Below you can see a section of the skill specification that prompts the user to input a string. The skill request body contains an object with multiple properties. Here I am showing the first two, "boolean" and "string". You can see the full list in the spec at the end of this document. In the API call above, you can also see the object with the single string "string" in it.
