Overview

Once you have completed all of the prerequisites listed on the home page, follow the steps below to install your first Watsonx Orchestrate custom skill.

Note

If you are using a shared Watsonx Orchestrate tenant, this skill may have already been installed by another user, and importing it will overwrite the existing skill. See the instructions after step 1 on how to modify the skill specification to make it unique.

Procedure

The following steps guild you through installing the "Hello World" skill

  1. Download the Hello World Skill spec to your local desktop

    Note: You can make your skill unique by making three modifications to the spec file; modifying the title on line 4, the summary on line 26, and adding a unique operationId inserted after summary on line 26. You can find an example of a modified spec file here where I added the letters jam to the title, summary and a new entry operationId.

  2. Login to Watsonx Orchestrate, navigate to the Skills page and import this new skill as shown in the digram



  3. After successful import, find the skill in your custom skill list and select Enhance this skill from the overflow menu as shown here



  4. From the Enhance page, click Publish



  5. Click on Add skills from the catalog to add Hello World your personal skill set. In the next screen you can search for the skill in the search bar.




    These skills will accept any string for an API key.



  6. Once you have successfully entered the API key, the skill will now exhibit a small blue checkbox to indicate that it is ready.



  7. Now you can see the skill is installed in your personal skill set and is visible from the Watsonx Orchestrate user chat interface.



  8. Now you are ready to run the skill. Continue to the next section to learn about enhancing and running the Hello World skill.
