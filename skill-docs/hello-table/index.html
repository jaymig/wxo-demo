Hello Table

Overview

The Hello Table skill calls an API using the HTTP GET method and returns a simple table. The response can be seen here.

Learning Objective

The main purpose of the Hello Table skill is to demonstrate how Watsonx Orchesrate can display a table and also to introduce the concept of an Application in Watsonx Orchestrate. The other goal was to give you an opportunity to explore some of the basic skill specificiation syntax and enhancement options.

Demo App

If you installed the Hello Table in the same tenant as you installed Hello World and added both skills to your personal skill set, you will now see the Demo Application in your home page of Watsonx Orchestrate. The Demo App is the application container that is used to group skills. Most of the demonstration skills in this document are contained within the Demo Application.

Column Title

In this skill, I introduced a new specification option: Title. You can see that the titles are configured using the "title" parameter in the Hello Table skill specification. If you look at the Hello Table output you will see the corresponding titles. Here is where you make the configuration in the skill spec file

Column Display

Watsonx Orchestrate skill enhancing permits the skill builder to customize the output. Here you can see in the enhance page, I can expand the output editor and, once I scroll down, I am able to set the value of the content to be displayed in the column.

In this case, I do not want to show the Last Name, so I set it to Empty ,

Now when you run it again, you will see the modified output:

Note

After you make such changes, you do need to republish the skill, and the remove and re-add it to your personal skill set, before running it again.
