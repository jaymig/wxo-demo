Array of Objects

Overview

The Array of Objects skill prompts the user to input rows for an array. The user has two options: Manually type in the data for each row, or upload a spreadsheet. The skill passes the array info in the body when calling an API using the HTTP POST method. The API returns the array and displays it in a table format. Screenshots showing the skill input and response can be seen here:

Note

After a file upload, the skill output displays the last page. In the case of my upload, there were 12 rows, and since the skill defaults to 5 rows per page, the resulting view shows the last two rows. If my XLS file has 13 rows, the skill would output the last page showing the last 3 rows. You can see the other rows by changing the items per page, or by using the right arrow to navigate to previous pages. Below you can see the first five rows, as I have navigated to the first page.

Learning Objective

The main purpose of the Array of Objects skill is to demonstrate how user input for arrays work. In particular, I wanted to point out that the user is able to upload an XLS spreadsheet to populate the array. You can find an example Fruit Farm products for use when testing this skill.

File Upload Details

Once you have initiated the Array of Objects skill, you can upload the spreadsheet by clicking on the upload file icon:

Please note that the XLS file should match the format of the template. A link to the template can be seen in the upload page. Again, You can find an example Fruit Farm products for use when testing this skill.

Data structure and format validation

The Array of Objects skill does some validation of the XLS file being uploaded. Below are two examples where the file uploads fail for different reasons. In the first example, the first entry in the Organic column causes an error because it is not a valid boolean data type. (e.g. "yes" was used instead of TRUE)

In the second example, the first column heading does not match the API which causes an error. (e.g. "name" was used instead of fruit_name)
