Dynamic Drop Down lists

Overview

The Dynamic Drop Down lists skill prompts the user to select an Organization and a Department, then echos those selections back to the user. The list of Organizations is fixed, but the Department list is dependant on the chosen Organization. The details of how this is accomplished are described below. This skill specification contains three skills. Dynamic Selection lists, List Organizations and List Departments. The user will only interact with Dynamic Selection lists. The two other skills are called by Dynamic Selection lists but not by the user directly. Here is a screenshot of each skill being added to my catalog.

When you are installing this example, be sure to select all three skills. Once the skills are added to the catalog, proceed to enhance and publish them, and then add all three skills to your skill set.

Learning Objective

The main purpose of the Dynamic Drop Down lists skill is to introduce drop down selections lists that are dependent on each other. In this example, the department list depends on the selection made in the organization list.

Note

As you may recall, in the Drop Down Lists skill example, we introduced drop down where the content was dynamically obtained from an external skill. The Dynamic Drop Down lists demo sill is extending that concept and also showing how to make one list dependant on the other.

List of organizations

Below you can see the skill specification section which calls the List Organizations skill to populate the first list. In the specification, you can see the use of "x-ibm-extension", which contains an "action" that calls the List Organizations skill using its skill_id (demo_skills__0.1__list_organization.demo.get).

This "x-ibm-extension", uses "mappings" feature to specify which item from the organization and ids will be displayed (e.g. label) and which items will be passed as a value to the next skill. The default behavior of Watson Orchestrate is to display the contents of the "lables" and to pass the contents of "values". 

        "name": "org",
        "in": "query",
        "description": "organizations",
        "required": true,
        "explode": true,
        "x-ibm-ui-extension": {
            "component": "dropdown",
            "actions": [
                {
                    "skill_id": "demo_skills__0.1__list_organization.demo.get",
                    "mappings": {
                        "labels": "nested.properties.arrayOfLabels.items.properties.label",
                        "values": "nested.properties.arrayOfLabels.items.properties.value"
                    },
                    "type": "data",
                    "params": {}
                }
            ]
        },
        "schema": {
            "type": "string"
        }

Here is the output of the List Organizations skill output as well as a screenshot of interacting via Postman. The output is an array of objects containing organization display names (label) and well as an organization identifier (value), which will be used when calling the Department skill.

Dynamic and dependant drop down list of departments

Passing the selected organization

The selected organization is dynamically passed to the List Departments skill using the query parameter, which responds with the relevant list of departments (e.g. based on the selected organization). Below you can see the section of the Dynamic Selection list skill which passes the selected org as a query parameter while calling the external List Departments skill. The "value":"reference" line informs the skill how to pass the value of the selected organization.

        "name": "departments",
        "in": "query",
        "description": "departments",
        "required": true,
        "explode": true,
        "x-ibm-ui-extension": {
            "component": "dropdown",
            "actions": [
                {
                    "skill_id": "demo_skills__0.1__list_departments.demo.get",
                    "type": "data",
                    "params": {
                        "org": {
                            "name": "org",
                            "value": "__reference__"
                        }
                    }
                }
            ]
        },
        "schema": {
            "type": "string"
        }

Here you can see a screenshot of Postman calling the List Departments skill, where the value of the query parameter is 'big_tech'

As the name implies, the output is an array of items containing department names.

[
    "Big Tech Development Dept",
    "Big Tech Planning Dept",
    "Big Tech Marketing",
    "Big Tech Support"
]

Skill response

The selected department together with the selected organization are both passed to the main skill using query parameter to the skill provider API using the HTTP GET method. The API returns a simple message informing the user of the selections as you can see in the screenshot above.
