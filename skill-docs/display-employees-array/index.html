Display Employees Array (complex object)

Overview

The Display Employees Array skill calls an API using the HTTP GET method and returns an array of complext objects. The response can be seen here.

Learning Objective

The main purpose of the Display Employees Array skill is to demonstrate how Watsonx Orchesrate can display an array of complex objects. Complex objects are objects that contain more than just primitive data types. One example of a complex object is an object that contains other objects. As you can see in the output display above, the Display Employees Array skill address column contains an object.

Array of Complex Objects

Watsonx Orchestrate skills are able to display an array of objects that contain both simple data types and other objects. In this case, the skill outputs two strings and an integer.

Here you can see the API output. Note that I collapsed the output for brevity. The complete output is provided below for your reference.
