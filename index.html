Overview

These examples were created to help you learn about Watsonx Orchestrate skills. Working with real examples is a great way to learn how to build Watsonx Orchestrate skills. I enjoyed creating these examples and I hope that you will also enjoy them and find them useful.

Note

Feel free to install and use the demonstration skills as you wish to help you learn about skill building in Watsonx Orchestrate.

Prerequisites

This documentation requires that you have the following:

  • Access to an instance of Watsonx Orchestrate
  • A login that is either a "builder" or "admin" role
  • Familiarity with importing custom skills

Documentation

The Documentation is organized into three main sections:

Getting Started

This section provides a very simple step by step to install and run your first skill.

Skill examples

The example skills are organized into the following categories:

  • Skills with Output - skills that demonstrate various output configurations.
  • Skills with Input and Output - skills that demonstrate both input and corresponding output configurations.
  • Dynamic skills - skills that demonstrate input selection lists that are dynamic in nature

Navigate to a skills page to see the details and acccess the skill spec file and try it out.
